# Fixtures multimodais v0.8.1

Arquivos sintéticos para testar entrada por imagem e PDF escaneado.

- `vitaguard_do_imagem_alpha.png` / `vitaguard_do_imagem_beta.png`: documentos de uma página em imagem.
- `vitaguard_do_scan_alpha.pdf` / `vitaguard_do_scan_beta.pdf`: os mesmos documentos inseridos em PDFs image-only, sem camada de texto nativo.

Todos os nomes, segurados, números e valores são fictícios e servem exclusivamente para teste acadêmico.
