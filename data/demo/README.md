# Dados de demonstração

A v0.7.2 distribui os três `PolicyRecord`s estruturados necessários ao modo Demo:

- Allianz D&O — condições gerais;
- AIG D&O AIG GO — condições gerais;
- VitaGuard D&O Executive Plus — documento sintético.

Os PDFs reais das seguradoras **não** são redistribuídos. Estes JSONs são artefatos estruturados produzidos e validados pelo pipeline VitaGuard.

A partir da v0.7.2, nenhuma versão antiga do projeto precisa permanecer no disco.
